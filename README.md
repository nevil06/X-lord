# X-Lord   Land Trust Infrastructure(work in progress)

A high-fidelity MVP for a sovereign land record accountability system. This platform establishes transparent ownership lineage, fraud detection, and multi-departmental workflow synchronization using a Next.js monorepo, FastAPI AI Intelligence, and Simulated Blockchain checkpointing.

## Step-by-Step Setup Guide

Follow these steps to boot up the complete architecture locally.

### 1. Prerequisites
- **Docker Desktop**: Must be installed and **currently running** on your machine.
- **Node.js** (v18+) and **npm**.
- **Python 3.9+** (optional, for AI intelligence).

### 2. Start the Database Layer (PostGIS)
Open a terminal in the root of the `land-order` project and start the database:
```bash
docker-compose up -d
```
*(Wait a few seconds for the database to fully initialize).*

### 3. Initialize the Express API & Database
Open a new terminal in the `apps/api` directory:
```bash
cd apps/api
npm install
# Sync the Prisma Schema with the PostGIS database
npx prisma db push
# Seed the database with demo parcels and users
npx ts-node prisma/seed.ts
# Start the Express API Server (runs on http://localhost:4000)
npm run dev
```

### 4. Start the AI Intelligence Service (FastAPI)
Open a new terminal in the `services/ai` directory:
```bash
cd services/ai
pip install -r requirements.txt
# Start the AI Server (runs on http://localhost:8000)
python main.py
```

### 5. Start the Next.js Frontend Portals
Open a new terminal in the `apps/web` directory:
```bash
cd apps/web
npm install
# Start the Next.js Web App (runs on http://localhost:3000)
npm run dev
```

## How to Test the Portals

Once all services are running, open your browser to **http://localhost:3000**.

### Citizen Portal (Default Landing)
- Navigate to `http://localhost:3000/`.
- View the **GIS Map Viewer** rendering colored land parcels.
- Search the public immutable registry by Survey Number.

### Officer Workstation
- Navigate to `http://localhost:3000/officer` (or click "Sign In" and select "Sub-Registrar").
- View the pending mutation queue.
- See the simulated AI Verification engine confidence scores and recent Blockchain commits.

### Collector Dashboard
- Navigate to `http://localhost:3000/collector` (or click "Sign In" and select "District Collector").
- View macro-level KPIs (High Risk Mutations, Active Disputes).
- Review automated fraud alerts generated by velocity anomaly detection.

### API Routes (Backend)
- **Lineage**: `GET http://localhost:4000/api/lineage/:uid` fetches the blockchain-verified ownership history.
- **Court**: `POST http://localhost:4000/api/court/freeze` issues a legal freeze on a parcel.
